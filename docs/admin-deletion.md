# 管理員刪除與復原

管理後臺可刪除整個個案，或該個案某日某類健康紀錄。這是可復原刪除，不是永久清除或釋放儲存空間。

- 名冊提供一般清單與「已刪除個案」；後者可以復原。刪除個案後伺服器立即阻擋登入資料讀取、寫入、照片讀取與邀請碼綁定，並移除排行榜項目。
- 個案原本的 active 狀態、LINE 綁定、照片、紀錄與目標都保留。復原不會重新啟用原先已停用的帳號，也不會復原先前單獨刪除的健康紀錄。刪除不會解除 LINE 綁定。
- 「查看紀錄」提供有效／已刪除紀錄清單，只允許對當日當類的最新版本刪除或復原。修訂歷程可查看原始內容與照片，不能單獨刪除某個歷史版本。
- 健康紀錄刪除及復原各新增一個版本，保留 previousId 鏈、原始照片與管理員操作資訊。所有讀取／統計都先取最後版本再過濾刪除標記，避免舊版復活。
- 刪除後個案可以重新填寫同日紀錄，但需提供新的照片佐證。舊刪除版本的復原會因版本衝突被阻止，不覆蓋新紀錄。
- 管理員操作須在確認視窗再次確認。伺服器驗證身分、版本與操作 ID；重送不重複執行，舊頁面不能覆蓋新的狀態。
- 原始資料仍存於私人 Patients／Records／Audit／Drive，沒有新增公開權限。個案端重新載入後會更新紀錄與統計，已經載入的畫面不會被遠端抹除。

後端 GET 提供 version: 3 與 adminTrash 能力標記。部署時先更新既有 Apps Script，再發布前端。自動測試使用虛構個案與 Google 服務替身；部署過程不刪除任何真實資料。
