# 護心餐桌

2026-09-21：將使用者確認的本機預覽整合到正式前端。首頁與個人選單提供「護心餐桌」，包含食物查詢、記錄入口及本週回顧。

- 查詢共 122 項、8 類，支援別名，按紅→黃→灰→綠排序；全數捲動顯示，無筆數資訊列。
- 四色說明分兩欄；食物小卡顯示逐品名插圖、特性與注意事項。只有紅／黃燈顯示逐項配對的健康選擇，未加入小目標。
- 122 張原創 SVG 放在 public/food-art，食物內容在 lib/food-catalog.json。個案介面不使用 ASCVD 縮寫。
- 飲食內容由使用者提供的 ASCVD 飲食文件及保腎護心工具食物範圍整理，未照搬 CKD／HF 的燈號；個別限鉀、限磷、限水指示優先。來源資訊與 draft 標記保留供維護，不代表完成正式營養審核。
- 記錄按鈕沿用現有照片必要條件、餐點問答、手動確認、私人圖片、保存與修訂流程；既有後端每天一筆飲食紀錄，未宣稱多餐保存。
- 最近一餐及本週回顧使用當前登入個案的既有紀錄；排除刪除、未來及過期修訂，不載入預覽假資料。沒有紀錄時顯示空狀態，不推斷全天攝取或疾病療效。
- 沒有後端 schema、權限、登入或 Apps Script 更新需求。既有運動、用藥、排行榜、成就、管理後台與匯出不變。

內容原則參考：[AHA 2026 dietary guidance](https://professional.heart.org/en/science-news/2026-dietary-guidance-to-improve-cardiovascular-health/top-things-to-know)。
