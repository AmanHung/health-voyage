# 飲食問答及航程顆數調整（2026-09-29）

- 修正分類器將未知照片一律回退為便當／餐盤的問題。只接受最高候選至少 0.35、與不同類候選差距至少 0.15 的食物類型，餐具及未知類不作餐點建議。分數是模型分數，不是經校準的正確率；模型未重新訓練，尚無真實照片集准确率驗證。
- 依既有護心餐桌主題增加料理、主食、蔬菜、蛋白質、配餐、加工品、湯量與糖飲的逐題提示，調整水果、飲料及三明治題目；飲料不顯示「沒有飲料」。保留手動選擇、照片必填及個案核對。
- 移除最後的飲食限制題。新問答 restrictedDiet 保持 null，不等同沒有飲食限制；後端接受 null，既有布林答案及匯出相容保留。
- 飲食保存後前往餐桌紀錄；回饋呈現在紀錄操作下方，不在首頁頂端。移除進度圈至船的細導引線，貝殼與數字放到船右側。
- 本機型別檢查與 169 項測試通過（含未知照片、候選歧義、null／true／false 舊新資料）。瀏覽器以合成資料檢查 320 px、200 顆顯示不裁切，貝殼在船右側且無細導引線，回饋在操作按鈕下方。
- Windows build:github 於 3065 模組轉換後中止且未輸出錯誤，正式建置待同一 commit 的 Linux CI 核對。登入入口與登入效能程式未修改。
