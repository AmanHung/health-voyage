# 個案紀錄 Excel 匯出

管理員登入 → 個案名冊上方 → 匯出所有個案紀錄 Excel → 選擇日期 → 一次下載所有個案 Excel。

- 起訖日期包含當日；開始日期預設不限，結束日期預設後臺提供的今日。留白代表不限。
- 每次下載重新取得 `admin.patients`，依序呼叫 `admin.records`，沿用後端管理員權限檢查與讀取稽核。包含停用及已刪除個案，不受名冊畫面篩選影響。每筆明細加入個案編號、姓名、暱稱及帳號狀態。
- 顯示讀取進度；任何個案讀取失敗即停止，不產生部分檔案。依序讀取不是資料庫同時間快照。
- 同日同類型按後端附加順序取最後版本。最新版本已刪除時整組排除，不回退舊版本。
- 工作表：匯出說明、個案名冊、運動紀錄、飲食紀錄、用藥回報、服藥明細。沒有紀錄的個案仍列入名冊，空工作表保留表頭。
- 用藥明細使用回報當下快照，不以現行處方覆蓋歷史；尚未回報項目不會憑空補為未服用。回報完成不是服藥率。
- 日期為文字，時間轉臺灣時間，數值維持數字，未填保持空白。自由文字寫入字串儲存格而不是公式。
- 檔案於瀏覽器產生，不傳往額外服務；不含照片、登入憑證或 LINE 識別碼。
- ExcelJS 透過動態載入，僅下載時載入。其 uuid 相依覆寫為 11.1.1，修正舊版本的 buffer bounds advisory；工作簿讀回測試涵蓋相容性。

驗證：`npm run typecheck`、`npm test`，包含實際 XLSX 寫入讀回、空資料、日期範圍、跨個案隔離、修訂去重、刪除排除、零步數與用藥狀態。

運動及飲食的照片欄位顯示「已上傳／未上傳」，不匯出圖片。填寫表單須有新照片或已保存原照片才能送出，辨識成功不是儲存條件。
