# 排行榜與自選頭像

更新日期：2026-09-18。

- 首頁排行榜採直列排名，上方呈現目前個案本月已記錄步數，下方顯示最多 20 位已加入排行榜的個案的暱稱、頭像與累積步數。同分並列，零步數不排名，停用／刪除帳號不入榜。管理員可在個案名冊勾選「加入步數排行榜」，勾選後自動儲存，測試成員亦可加入；取消不刪除紀錄。既有未設定帳號維持正式成員加入、測試成員不加入的預設。
- 首頁「換頭像」與個人選單均進入既有「我的帳號」。選擇六款預設圖案或 JPG／PNG 後按「儲存設定」，成功後首頁與個人選單使用最新頭像，排行榜重新讀取。
- 原有帳號沒有 avatar 欄位時使用小帆船。舊前端只傳 nickname 時保留已保存頭像；新增欄位不需要資料搬移。
- 上傳圖片在裝置端置中裁切並重新編碼為 128 × 128 JPEG，資料 URL 最長 16,000 字元；後端另驗證 JPEG 內容與尺寸。只在私人 Patients JSON 保存縮圖，不建立公開照片網址，原圖不送出。
- 頭像由已登入的原有排行榜 API 回傳；既有運動／飲食私人照片讀取權限不變。切換預設圖案並儲存會取代自訂頭像。
- 對應後端 GET 服務版本 6，包含 leaderboardAvatars 與 adminLeaderboard 能力。發布順序為既有 Apps Script 部署的新版本，再推送前端至 main 交由 GitHub Actions 建置及發布；保留原部署網址與 OAuth 權限。
- 既有任務、活動目標、用藥清單、月曆、歷史紀錄、徽章及整批匯出維持原流程。自動測試使用合成資料，手機實機與真實 LINE 身分保存仍須另行驗收。

- 排行榜資格使用獨立 leaderboardEnabled 設定，不受個案修改暱稱或頭像影響；只有管理員可變更，採鎖定及版本檢查避免過期名冊覆寫，成功變更記錄稽核。已開啟的個案首頁重新載入後更新榜單。
