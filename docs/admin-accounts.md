# 管理員帳號管理

管理後臺的「管理員帳號管理」可新增 Google 帳號，確認後即可使用 Google 登入。管理員具有完整個案及管理員管理權限；僅需維護指定個案用藥者應使用原有藥師指派功能。

名單存在私人 Apps Script 的 ADMIN_ACCOUNTS 設定，未設定時沿用原始管理員。操作使用鎖定、版本檢查及重送識別，並記錄稽核。至少保留一位管理員；畫面不提供移除目前帳號，須由另一位管理員操作。移除管理員權限不刪除既有個案及紀錄。若此人仍有藥師指派，保留該指派範圍。

每次請求都重新判定 Google 帳號的角色，包括快取登入狀態；不需等待登入憑證失效才撤銷管理員存取。部署此功能本身不新增任何帳號。
