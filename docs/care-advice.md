# 照護建議與分類紀錄

管理名冊保留原有帳號、用藥、目標、獎品及匯出功能，新增用藥／運動／飲食分類次數及逐版本 NEW。計數以個案、日期、種類的目前有效紀錄為準；修訂不重複計數，刪除排除，未服用／有疑問仍計為回報紀錄，不能解讀為服藥率。尚未查看的既有紀錄也會標記 NEW。

## 保存與權限

- 新增 CareAdvice、CareReads 兩個工作表，位於既有私人紀錄試算表；讀取缺表時視為空集合，首次授權寫入時在既有寫入鎖內建立，不需要執行初始化，也不改存取權限或 OAuth scopes。
- CareAdvice 逐次附加建議版本，包含個案、日期、種類、來源紀錄版本、內容、發布／撤回狀態、操作者、時間、重送編號與指紋。只有管理員可發布或撤回；不可覆寫已更新／已刪除紀錄的來源版本，建議更新也須核對前版 ID。
- CareReads 保存管理員查看的紀錄版本及個案確認閱讀的建議版本。依已驗證身分決定操作者，管理員彼此獨立；個案僅能讀取與確認自己的有效已發布建議。重複確認不重複寫入。
- 個案 DTO 不提供管理員識別碼、重送指紋或內部列號。個案只看到「照護團隊」、發布時間與內容；可稽核操作者保留於後端建議版本及 Audit。
- NEW 與已讀狀態均存於後端，不使用瀏覽器時間戳作正式依據。照護建議不改變原始紀錄、貝殼或用藥完成狀態。

## 介面與提醒

分類按鈕於原個案下方展開；每筆紀錄點開後才保存該管理員的查看狀態，失敗時保留 NEW 並提示重試。有效／已刪除篩選、照片及修訂歷程與刪除復原保留。既有「查詢個案紀錄」在有分類入口的使用中個案隱藏，已刪除個案仍保留唯讀查詢。

建議輸入最多 600 字，支援分段。發布／更新／撤回均先核對個案與紀錄；修改歷程保留。個案首頁提供建議與未讀數，登入時依序呈現新建議、簽到、回診提醒。關閉建議視窗不算已讀，「我已閱讀」才保存。新版建議重新成為未讀；來源紀錄修改時標示依修改前資料提供，紀錄刪除時隱藏相關建議。閱讀不代表採納或完成建議。

個案可從首頁重新載入建議，亦可在對應日曆、用藥與歷史紀錄查看。沒有 LINE 主動推播或即時 WebSocket；發布後於下次登入或重新載入取得。

## 發布與驗證

正式前端需 GitHub Actions／Pages 發布，後端需同步更新既有 Apps Script 部署。服務版本 13，能力 careAdvice、adminRecordCounts。不可將 work/ 的合成傳輸、測試身分或預覽控制部署為正式入口。

本次本機型別檢查及 195 項測試通過，包含來源版本與前版建議衝突、重送去重、建議撤回、逐管理員 NEW、逐個案隔離、已刪除／停用限制、空資料表及寫入鎖。正式元件與模擬 Apps Script 服務完成合成瀏覽器測試，包含提醒順序、發布、閱讀、撤回及管理員狀態分離。Windows 正式建置轉換模組後中止；發布以同一提交 CI Linux 成功為準。合成測試不代表真實手機登入或正式資料寫入已驗收。
