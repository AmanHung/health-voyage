# 健康航程：第一階段改版

日期：2026-09-09

## 本階段

- 正式入口 `production/` 改為海洋藍、青綠與白底，搭配原創海岸與海島插圖。
- 新增「今日、航程、成就、我的」導覽；保留原有個人選單與登出。
- 今日頁保留三項真實紀錄入口，顯示本週紀錄與下一站。
- 航程頁提供三個累積里程碑與原有暱稱步數榜。
- 成就頁依後端傳回的紀錄計算六枚紀念章，空白帳號沒有預設成就。
- 健康紀錄與任務月曆移至「我的」；餐點回饋、照片、修改與修訂流程保留。
- 紀錄視窗沿用相同的配色、字級、大按鈕與回饋樣式。

## 計算規則

- 使用後端的臺灣日期，週一至週日為一週。
- 本週小挑戰為五個紀錄日。有任一項已保存紀錄即可算一天。
- 同一天、同類任務只取最新版本；同一天最多累積一個紀錄日。
- 累積一、七、二十一個紀錄日，分別抵達啟程港、活力島、好習慣灣。
- 紀念章：首次紀錄、五天運動紀錄、五天飲食紀錄、五天用藥回報、七天與三十天累積紀錄。
- 日期與類別決定參與成就；修改步數、飲食內容或用藥狀態不會重複加分。
- 誠實的未服用／有疑問回報一樣計算參與；不計算或宣稱服藥遵從率與疾病改善。
- 本週進度每週重新計算，過去累積不因中斷歸零；成果根據伺服器紀錄重建，不儲存於共用瀏覽器帳號狀態。
- 保存成功後才顯示完成回饋。支援系統「減少動態效果」設定。

## 素材

使用內建 image_gen 生成兩張無文字、無 UI 的網站插圖，各生成一次，再以 Sharp 轉成 WebP。未新增網站端 AI 服務。

- `public/voyage/coast.webp`：1536 × 512，約 101 KB。
- `public/voyage/islands.webp`：900 × 1350，約 201 KB。

提示重點：成人友善的精緻海洋藍／青綠海島插畫，白色海鳥配藍領巾。橫幅左側天空留白，右側帆船與燈塔；直幅上右燈塔港、中左綠島、下右海灣，海面供前端疊加航程節點。

## 驗證與後續

新增資料計算及元件輸出測試，涵蓋空白帳號、重複修訂、真實用藥狀態、跨年週次、未來日期與中斷後保留成果。需搭配既有型別檢查、完整測試與 GitHub Actions 正式建置。

此階段沒有調整 Google 後端資料結構、處方或飲食問答規則。後續階段再處理個人活動目標、餐點問答減量與處方時段／提醒／待關懷流程。正式臨床及多手機實機驗收仍依接手文件逐項完成。
