# 管理員直接兌換獎品

管理名冊展開個案後，獎品兌換區列出四項獎品。管理員不論個案目前貝殼數多少，皆可勾選任一獎品建立兌換並完成交付，個案不需先申請；成功保存後才勾選，失敗顯示錯誤並可重試，已完成項目停用，未達參考門檻也可勾選。

個案端改為查看獎品狀態，完成後顯示「已兌換」。獎勵頁進入、切回及可見時每 15 秒讀取本人的兌換狀態，離開頁面取消讀取；更新失敗保留最後已知狀態並顯示重試。

個案航程保留 30／50／80／200 顆目標；管理員兌換不受門檻限制。累積貝殼不扣除，每項仍限一次。既有待領取紀錄完成時保留原 ID 與申請時間，不重新檢查已取得資格後下降的貝殼數。新兌換由後端核對管理員身分、有效個案及寫入鎖，重送不重複建立或改寫完成時間，異動記錄於 Audit。

新增 health.adminRedeem（管理員專用）與 health.status（個案只讀本人狀態）。獲指派藥師原有讀取／確認交付流程保留，不授予管理員直接兌換權限。保留 health.redeem 供尚未更新的既有前端相容使用。GET 服務版本 17，新增能力 adminRedemptionAnyTotal，保留 adminDirectRedemption、rewardStatus；資料 schema 與 OAuth 權限不變。
