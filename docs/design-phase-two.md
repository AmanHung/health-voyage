# 第二階段：飲食紀錄減少等待與重填

日期：2026-09-09

本次改善操作路徑，保留一次一題與既有必要確認欄位；不以縮短問卷為由推定食材、份量或飲食限制。

- 已完成的餐點紀錄直接開啟核對摘要。
- 每項答案及餐別均可單獨修改，選完直接返回摘要，其餘答案保留。
- 改變餐點類型前可以返回原摘要；選定新類型後，清空舊內容並重新確認。
- 更換照片仍清空舊問答；新照片及舊照片的修訂流程保持原樣。
- 模型辨識期間提供「自行選擇餐點類型」。轉為手動或更換照片後，先前的模型結果不再更新畫面。
- 分類程式延後至需要辨識照片時才載入，首頁不主動載入該模組。
- 新選取照片改為可展開的縮圖，問題區更容易閱讀；每次換題會將題目帶入紀錄視窗的可視位置。
- 完成核對才開放儲存；送出函式也再次檢查，避免以 Enter 提前送出未完成的餐點。
- 舊紀錄若已有照片但尚無完整問答，可直接補齊，不要求重新上傳同一張照片。

本次未變更 Google 後端、資料結構、原始衛教規則或付費 AI 設定。新品項的必要回答數沒有減少，實際耗時改善仍須以手機使用者試用量測。下一階段的個人活動目標需以照護團隊確認的目標為基礎。
